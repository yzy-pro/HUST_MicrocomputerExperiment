# 微机实验3——可回收垃圾分类回收系统设计（C8051F310）
## 一、实验基本信息
### 1. 实验名称
可回收垃圾分类系统设计
### 2. 硬件载体
C8051F310 单片机实验平台（C8051F310 EVM开发板）
### 3. 实物场景
设备为小区落地式智能垃圾分类回收柜，分为塑料纸张、玻璃金属、厨余垃圾、危害垃圾四类投放仓，配套触控操作屏、状态数码管、进度流水灯、蜂鸣器、功能按键。

### 4. 开发板硬件单元说明
| 硬件单元 | 功能说明 |
| ---- | ---- |
| 4路数码管 | 依次对应：塑料纸张、玻璃金属、厨余垃圾、危害垃圾，显示垃圾桶剩余容量 |
| 流水灯D1~D8 | 开盖8s倒计时进度条，实时展示剩余开盖时长 |
| F1/F2/F3/F4 | 四类垃圾开盖投递按键 |
| 数字键0~9 | 多袋投放数量输入（提高功能） |
| Kint提前关盖键 | 开盖8s内手动提前关桶盖，触发外部中断 |
| F6物业清理键 | 物业清空垃圾桶，恢复容量至最大值9 |
| 蜂鸣器 | 容量不足/投放错误时报警1s |

## 二、实验目的
1. 加深理解C8051F310单片机I/O口、键盘与数码管显示电路原理；
2. 掌握定时器/计数器、外部中断的编程应用，掌握代码调试方法；
3. 学会使用Configuration Wizard 2软件配置单片机硬件资源，自动生成初始化代码；
4. 锻炼工程问题分析能力、单片机软硬件综合实践能力。

## 三、实验基础功能需求
### 1. 系统初始化规则
系统上电初始化后，随机生成4个0~9整数，分别代表四类垃圾桶剩余可投放容量（最大值9）。

### 2. 开盖投递基础逻辑（F1~F4按键）
1. **桶满判断**：若对应数码管数值为0（桶已满），按下对应F键：蜂鸣器鸣响1s，数码管显示`F`（FULL），拒绝开盖；
2. **正常开盖**：垃圾桶有剩余容量时，按下F键开启对应桶盖，开启总时长固定8s；
   - 开盖期间：对应数码管以5Hz频率闪烁；D1~D8流水灯作为倒计时进度条；
   - 再次按下该F键：垃圾桶容量-1，实现单袋投放，可重复按键连续投放；
3. **自动关盖机制**：采用定时器中断实现高精度1ms级延时，开盖满8s自动关闭桶盖，停止倒计时流水灯、数码管停止闪烁。

### 3. 提前关盖中断功能
开盖8s倒计时未结束时，按下`Kint`提前关盖按键，触发外部中断，立即停止定时器计时，强制关闭桶盖。

## 四、提高拓展功能（85分以上选做）
1. **全局状态同步显示**：按下F1~F4任意开盖键，4个数码管同步刷新显示全部四类垃圾箱当前剩余容量；
2. **多袋批量投放**
    - 开盖后可按下数字键1~9，一次性投放对应袋数，兼容原有单袋投放逻辑；
    - 若输入袋数＞当前垃圾桶剩余容量：蜂鸣器鸣响报警，数码管显示`E`（ERROR），桶盖保持关闭；1s后数码管恢复原有容量显示；
3. 可自主增加个性化拓展功能（如物业一键清空、投放计数统计等）。

## 五、核心技术要求
1. 延时、8s倒计时全部基于**定时器中断**实现，延时精度≤1ms；
2. 数码管5Hz闪烁、流水灯进度条、蜂鸣器报警、按键中断、定时器中断多任务协同运行；
3. 使用Configuration Wizard 2工具配置单片机外设（I/O、定时器、中断），生成初始化代码。
