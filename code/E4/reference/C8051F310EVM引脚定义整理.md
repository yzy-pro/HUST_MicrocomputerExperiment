# C8051F310EVM 单片机引脚定义整理

来源：`reference/C8051F310EVM使用指南（2017）.pdf`

## 1. 数码管（4位，LG3641AH，共阴）

### 1.1 段控引脚

| 数码管段 | MCU引脚 |
|---|---|
| a | P1.7 |
| b | P1.6 |
| c | P1.5 |
| d | P1.4 |
| e | P1.3 |
| f | P1.2 |
| g | P1.1 |
| dp | P1.0 |

说明：段控输出高电平时，对应段点亮。

### 1.2 位控引脚

| 位控信号 | MCU引脚 |
|---|---|
| B | P0.7 |
| A | P0.6 |

位选逻辑如下：

| B | A | 点亮位 |
|---|---|---|
| 0 | 0 | 数码管0 |
| 0 | 1 | 数码管1 |
| 1 | 0 | 数码管2 |
| 1 | 1 | 数码管3 |

## 3. LED指示灯阵列（D1-D8，经74HCT164）

### 3.1 74HCT164控制引脚

| 控制信号 | MCU引脚 |
|---|---|
| DAT_IN | P3.3 |
| CLK | P3.4 |

### 3.2 74HCT164输出与LED对应

| 74HCT164输出 | 指示灯 |
|---|---|
| Q1 | D1 |
| Q2 | D2 |
| Q3 | D3 |
| Q4 | D4 |
| Q5 | D5 |
| Q6 | D6 |
| Q7 | D7 |
| Q8 | D8 |

说明：Q输出为0时，对应LED点亮。

## 4. 蜂鸣器与独立指示灯D9

| 控制对象 | MCU引脚 | 有效电平 |
|---|---|---|
| 蜂鸣器 | P3.1 | 1（高有效） |
| D9（黄光） | P0.0 | 0（低有效） |

## 5. A/D输入接口

| 项目 | 内容 |
|---|---|
| A/D输入引脚 | P3.2 |
| 输入范围 | 0 - 3.3V |
| 电压源选择 | 跳线JP1 |

JP1可选输入：

| JP1位置 | 输入电压 |
|---|---|
| EXT | 外部输入（0 - 3.3V） |
| 0.0 | 0 |
| 0.25 | 0.25 × 3.3V |
| 0.5 | 0.5 × 3.3V |
| 0.75 | 0.75 × 3.3V |

补充：
- `EXT` 从连接器 `J2` 输入。
- `JP1` 同时只能插一只跳线片。

## 6. UART接口（连接器J3）

| 信号 | MCU引脚 | J3针脚 |
|---|---|---|
| TXD | P0.4 | 1 |
| GND | - | 2 |
| RXD | P0.5 | 3 |

接口电平：3.3V。

## 7. 独立按键与复位

| 功能 | 名称 | MCU引脚/说明 |
|---|---|---|
| 外部触发按键 | KINT | P0.1，按下为低电平 |
| 手动复位按键 | KMR | 外部复位键，按下并松开触发复位 |

## 8. 调试与电源接口

| 接口 | 说明 |
|---|---|
| JTAG（J4） | 10芯接口，连接U-EC5仿真器进行调试 |
| 电源接口（J3） | 5V电源适配器输入 |
