# C8051F310EVM 数码管驱动例程

本例程用于 C8051F310EVM 开发板 4 位数码管动态显示：
- 上电显示 `0000`
- 约每 `1` 秒加 `1`
- 到 `9999` 后回到 `0000`

示例源码：`main.c`

## 1. 硬件引脚映射

根据开发板手册：

- 段控（高电平点亮）
  - `P1.7..P1.0 -> a b c d e f g dp`
- 位控
  - `P0.7 = B`
  - `P0.6 = A`
  - 位选关系：
    - `BA=00` -> 数码管0（个位）
    - `BA=01` -> 数码管1（十位）
    - `BA=10` -> 数码管2（百位）
    - `BA=11` -> 数码管3（千位）

## 2. 初始化配置（与 reference/config.asm 对齐）

核心配置：

- `P0MDOUT = 0xC0`（P0.6/P0.7 推挽输出）
- `P1MDOUT = 0xFF`（P1 全部推挽输出）
- `XBR1 = 0x40`（使能 Crossbar）
- `OSCICN = 0x83`（内部 24.5MHz）
- 关闭看门狗：`PCA0MD &= ~0x40`

## 3. 段码表

当前使用共阴数码管高有效段码：

`0xFC, 0x60, 0xDA, 0xF2, 0x66, 0xB6, 0xBE, 0xE0, 0xFE, 0xE6`

即数字 `0~9` 对应段码。

## 4. 显示原理

1. `scan_one()`：输出某一位数字的段码，并设置位选 `BA`。
2. `refresh_4digit()`：按 `个位 -> 十位 -> 百位 -> 千位` 依次扫描。
3. 主循环中先连续刷新约 200 次形成稳定显示，再执行一次 BCD 加一。

## 5. 常见问题

- 数码管不亮但板载 LED 亮：
  - 检查 `P0MDOUT/P1MDOUT/XBR1/OSCICN` 是否与本例一致。
  - 检查段码极性。若硬件为低有效，可把 `P1 = seg` 改为 `P1 = ~seg`。
- 数字闪烁明显：
  - 减小单次扫描延时或增加扫描频率。
- 计时不准：
  - 当前为软件延时，若需高精度 1s，建议改为定时器中断。

## 6. 纯汇编实现说明（当前工程版本）

当前工程中的 [main.c](/home/yzy/code/MicrocomputerExperiment/E4/code/E4/src/main.c) 已改为“C 入口壳 + 纯汇编逻辑”：

- `main(void) __naked` 仅承载 `__asm ... __endasm`
- 数码管初始化、动态扫描、BCD 计数与延时全部在汇编内完成
- 不再依赖 C 函数参与显示逻辑

汇编中使用的关键资源：

- SFR：`PCA0MD/P0MDOUT/P1MDOUT/XBR1/OSCICN`
- 变量（IRAM）：`0x30~0x34`
  - `0x30~0x33`：个位/十位/百位/千位
  - `0x34`：约 1 秒刷新计数
- 段码表：`SEG_TAB`（`0~9`）

主循环流程：

1. 执行板级初始化（与 `reference/config.asm` 对齐）。
2. 扫描 4 位数码管若干轮（形成稳定视觉显示）。
3. 对 4 位 BCD 做 `+1` 及进位处理。
4. 无限循环。

说明：

- 该方案依然通过 SDCC 构建，但业务逻辑是纯汇编。
- 若要进一步提高“1 秒”精度，建议改为定时器中断驱动。
