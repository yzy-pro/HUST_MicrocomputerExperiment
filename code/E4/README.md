# 智能垃圾分类回收系统 — C8051F310EVM 使用说明

## 硬件对应关系

| 开发板元件 | 对应功能 |
|---|---|
| 4 位数码管（左→右） | 塑料纸张 / 玻璃金属 / 厨余垃圾 / 危害垃圾的剩余容量（0–9） |
| D1–D8 流水灯 | 开盖倒计时进度条（8s 满格，逐渐熄灭） |
| D9 黄色指示灯 | 桶盖状态（亮 = 开盖中，灭 = 已关闭） |
| 蜂鸣器 | 满桶报警（鸣响 1 秒） |
| K10 / K11 / K12 / K13（F1–F4） | 分别对应四类垃圾桶的开盖投递按键 |
| K1–K9 | 开盖后批量投放 1–9 袋 |
| K14（F5） | 进入计算器模式；计算器模式下为 Back |
| Kint 按键 | 提前关盖（触发外部中断） |
| K15（F6） | 物业清空：将所有桶容量恢复至 9 |

## 上电初始化

系统上电后自动随机生成 4 个 0–9 的整数，分别显示在 4 位数码管上，代表各垃圾桶当前的剩余投放容量。每次复位（KMR 按键）均重新随机生成。

## 功能演示步骤

### 1. 正常开盖投递

1. 确认对应数码管显示值 > 0（桶未满）。
2. 按下对应功能键（K10–K13 / F1–F4）：
   - D9 亮，表示桶盖已打开。
   - 对应数码管以 **5 Hz 频率闪烁**。
   - D1–D8 流水灯全亮，开始倒计时。
3. 可用以下任意方式投放：
   - 再次按下同一个功能键，投放 1 袋。
   - 按下 K1–K9，一次性投放对应袋数。
4. 投放成功后，对应数码管显示值扣减相应数量。
5. 8 秒后桶盖自动关闭：D9 灭，流水灯全灭，数码管停止闪烁。

### 2. 批量投放容量不足

开盖后若输入袋数大于当前桶剩余容量：
- 蜂鸣器鸣响约 1 秒。
- 该数码管显示 `E`（ERROR），1 秒后自动恢复容量数字显示。
- 桶盖立即关闭，拒绝本次投放。

### 3. 提前关盖

开盖期间按下 **Kint** 按键，触发外部中断，桶盖立即关闭：D9 灭，流水灯立刻全灭。

### 4. 满桶拒投报警

当某桶容量为 0 时，按下对应功能键：
- 蜂鸣器鸣响约 1 秒。
- 该数码管显示 `F`（FULL），1 秒后自动恢复容量数字显示。
- 桶盖不会打开。

### 5. 物业清空

按下 **K15（F6）** 按键：
- 所有 4 个数码管恢复显示 `9`（满容量）。
- 当前开盖状态被清除，流水灯关闭。
- 蜂鸣器鸣响约 1 秒作为确认。

### 6. 计算器模式

正常模式下按下 **K14（F5）** 进入计算器模式，数码管熄灭。计算器模式下：
- K0–K9 输入 0–9，每个操作数最多 2 位，输入数字右对齐显示。
- KF1/KF2/KF3/KF4 分别表示加/减/乘/除，按下后第 1/2/3/4 位数码管显示 `8` 作为运算符提示。
- KF5 为 Back，可退格、返回上一步或清除结果。
- KF6 为等号，输出计算结果。
- 除法结果固定显示为前两位商、后两位余数。
- 按下 Kint 退出计算器模式，恢复正常垃圾投放模式。

## 编译与烧录

```bash
# 编译（生成 build/Debug/c8051f310.hex）
bash ./scripts/build.sh

# 烧录（默认串号 EC320126621，C2 接口）
bash ./scripts/flash.sh

# 列出已连接设备
bash ./scripts/flash.sh -l

# 指定设备烧录
bash ./scripts/flash.sh -s <串号> -t c2
```

## 代码结构

```
inc/
  sfr.inc       SFR 地址定义
  iram.inc      内部 RAM 共享变量定义
src/
  vectors.asm   中断向量表（0x0000）
  init.asm      硬件初始化 + 程序入口
  isr.asm       外部中断0（Kint）+ Timer0（1ms 定时）
  display.asm   4 位数码管动态扫描
  keypad.asm    4×4 矩阵键盘扫描
  led_bar.asm   74HCT164 流水灯驱动
  tables.asm    段码表、LED 映射表、键码映射表
  main.asm      主循环 + 垃圾桶状态机
  calculator.asm 计算器模式状态机
```
