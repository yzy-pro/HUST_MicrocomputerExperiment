# C8051F310EVM 按键控制 LED 翻转例程

本例程实现：
- 扫描 `4x4` 矩阵键盘
- 在数码管显示当前按键名称（`Kx` / `KFx`）
- 当按下 `K1~K9` 时，翻转对应 LED 状态
  - `K1->D1` ... `K8->D8`
  - `K9->D9`
- 上电初始状态：`D1~D9` 全部熄灭

示例源码：`main.c`

## 1. LED 硬件定义

### 1.1 D1~D8（LED 阵列）

通过 `74HCT164` 串行移位寄存器驱动：

- `P3.3 -> DAT_IN`
- `P3.4 -> CLK`
- 输出对应：`Q1~Q8 -> D1~D8`
- 低电平亮：`Q=0` 点亮对应 LED

程序中用 `LEDREG`（8 位）保存 D1~D8 状态：
- 位值 `1` 表示灭
- 位值 `0` 表示亮

### 1.2 D9（独立 LED）

- `P0.0` 控制
- 低电平亮
- 程序中用 `LED9S` 保存状态：
  - `0` 表示灭
  - `1` 表示亮

## 2. 关键初始化

- `P3MDOUT = 0x18`：配置 `P3.3/P3.4` 为推挽输出（驱动 74HCT164）
- `P0MDOUT = 0xC0`：数码管位选
- `P1MDOUT = 0xFF`：数码管段选
- `P2MDOUT = 0x0F`：键盘行输出、列输入
- 关闭看门狗，开启 Crossbar，设置内部振荡器

## 3. 按键到 LED 的控制关系

只对数字键 `K1~K9` 生效：

- `K1` 翻转 `D1`
- `K2` 翻转 `D2`
- `K3` 翻转 `D3`
- `K4` 翻转 `D4`
- `K5` 翻转 `D5`
- `K6` 翻转 `D6`
- `K7` 翻转 `D7`
- `K8` 翻转 `D8`
- `K9` 翻转 `D9`

功能键 `KF1~KF6` 不改变 LED 状态。

## 4. 控制实现方法

1. 按键扫描得到 `scan_code`。
2. 通过 `KEY_REMAP_TAB` 做实物键位重映射。
3. 显示按键名。
4. 若为 `K1~K9`，执行对应 LED 状态异或翻转。
5. 调用 `APPLY_LED_STATE`：
   - 将 `LEDREG` 串行移位送入 74HCT164（更新 D1~D8）
   - 根据 `LED9S` 输出 `P0.0`（更新 D9）
