# C8051F310EVM 矩阵按键扫描与数码管显示例程

本例程用于 C8051F310EVM 开发板：
- 扫描 `4x4` 矩阵键盘
- 当按键按下时，在 4 位数码管显示该按键名称
- 数字键显示为 `Kx`，功能键显示为 `KFx`

示例源码：`main.c`

## 1. 硬件引脚映射

### 1.1 数码管

- 段控：`P1.7..P1.0 -> a b c d e f g dp`（高电平点亮）
- 位控：
  - `P0.7 = B`
  - `P0.6 = A`
  - `BA=00/01/10/11 -> 数码管0/1/2/3`

### 1.2 矩阵键盘

- 行输出（KO）：`P2.0~P2.3`
- 列输入（KI）：`P2.4~P2.7`

## 2. 初始化配置

与开发板参考配置对齐：

- `P0MDOUT = 0xC0`（位选引脚推挽输出）
- `P1MDOUT = 0xFF`（段选引脚推挽输出）
- `P2MDOUT = 0x0F`（低4位输出，高4位输入）
- `P2MDIN  = 0xFF`（数字输入）
- `XBR1 = 0x40`（使能 Crossbar）
- `OSCICN = 0x83`（内部振荡器）
- 关闭看门狗：`PCA0MD &= ~0x40`

## 3. 扫描逻辑

采用逐行扫描：

1. 依次置 `P2` 为 `0xFE/0xFD/0xFB/0xF7`，每次拉低一行。
2. 读取列输入（`P2.4~P2.7`）判断是否有按键按下。
3. 做一次短延时后复读确认（消抖）。
4. 得到原始扫描键值：`scan_code = row * 4 + col`。

## 4. 显示逻辑

- 数码管动态扫描显示
- 显示格式：
  - 数字键：`Kx`
  - 功能键：`KFx`

示例：按下 `K7` 显示 `K7`，按下 `KF3` 显示 `KF3`。

## 5. 实物键位重映射

本板实物键位与原始矩阵扫描顺序存在偏差，程序内已加入重映射表：

- `KEY_REMAP_TAB`（在 `main.c` 中）
- 流程：`scan_code -> remap -> 键名显示`

这样可保证显示名称和你实际按下的键一致。
